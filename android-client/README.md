# LegacyDisplay Android Client

Veja [build, instalação e operação](../docs/ANDROID.md), [protocolo](../protocol/PROTOCOL.md) e [validação no tablet](../docs/VALIDATION.md).

O build usa Kotlin 2.1.20, AGP 8.9.2, Gradle 8.11.1 e Android API mínima 24. O dashboard inicial é incluído diretamente de `../protocol/examples/dashboard.json` nos assets, evitando uma cópia independente.
